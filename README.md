# 💰 App de Controle de Finanças

Aplicação completa para gerenciamento de finanças pessoais, permitindo o controle de receitas, despesas e análise de gastos de forma simples e eficiente.

---

## 📱 Demonstração

<!-- Adicione prints ou GIF aqui -->

* Tela de login
* Dashboard
* Lista de transações
* Cadastro de receitas/despesas

---

## 🚀 Funcionalidades

* 🔐 Autenticação de usuário (JWT)
* 💵 Cadastro de receitas e despesas
* 🗂 Organização por categorias
* 📊 Resumo financeiro
* ✏️ Edição e exclusão de registros
* 📅 Controle por data

---

## 🧠 Diferencial

Aplicação com backend próprio utilizando API REST desenvolvida em Delphi, demonstrando domínio de regras de negócio, persistência de dados e autenticação.

---

## 🛠 Tecnologias utilizadas

### Backend

* Delphi
* Horse (API REST)
* JWT

### Banco de dados

* Firebird

### Arquitetura

* API RESTful
* Separação de camadas (rotas, serviços, banco)

---

## 📦 Estrutura do projeto

```id="c4pt3d"
/backend   -> API Delphi + Horse
/database  -> Banco Firebird (.fdb)
```

---

## ⚙️ Como rodar o projeto

### 1. Clonar repositório

```id="o9lq7a"
git clone https://github.com/appsoft-lucio/minhasFinancas
```

### 2. Configurar banco de dados (Firebird)

* Instalar Firebird Server
* Restaurar ou utilizar o arquivo `.fdb` disponível em `/database`

### 3. Executar API

* Abrir o projeto no Delphi
* Compilar e executar
